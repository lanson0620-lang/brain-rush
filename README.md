# 脑力觉醒 Brain Rush · 数字风暴

零依赖的随机四则运算脑力训练游戏。纯 HTML + CSS + JavaScript 单文件实现，
无框架、无构建工具、无外部资源（CDN / 字体 / 图片 / 音频一律不用）。

## 玩法

- **极速挑战**：3 颗生命，答错或超时扣一条命，冲击最高分
- **60 秒生存战**：固定 60 秒，关闭生命限制，拼答题数量与正确率
- **数字连锁**：2～5 步连续算式，严格遵守运算优先级

## 特性

- 随机题目真实算法生成：**除法保证整除且除数非零**，减法默认不出负数
- 四档难度 + 可选动态难度（随分数与连击自动升档）
- 完整积分 / 连击 / 生命 / 评级系统（C · B · A · S · SS）
- 键盘、触屏双输入；手机端专用数字键盘
- Web Audio API 实时合成音效，零音频文件
- localStorage 本地存档（最高分 / 最佳连击 / 最佳正确率 / 最近对局）

## 无障碍

- 全部文字对比度达 WCAG AA（≥4.5:1），实时审计
- 键盘可完成全部操作，焦点始终可见
- 屏幕阅读器实时播报题目、得分、连击与结算
- 弹层焦点陷阱 + 焦点归还 + 背景 inert
- 跳转链接、地标语义、标题层级完整
- 触控目标 ≥44×44（WCAG 2.5.8）
- 尊重 `prefers-reduced-motion`

## 运行

直接用浏览器打开 `index.html` 即可，无需安装任何东西，断网也能完整游玩。
